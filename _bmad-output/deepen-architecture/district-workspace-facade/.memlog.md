Centralize cross-resource invalidations so any mutation (bot connection, group addition, hokim creation) automatically invalidates ['district', districtId, 'readiness'] alongside the entity-specific key.
- (decision) Decision 4: Test surface is the consolidated DistrictWorkspace domain contract tested with real React Query providers and mock service worker / contract stubs, removing brittle inter-hook mocks.
