Problem: ADR-0001 is partially abandoned: modules import concrete adapters by path in 180+ places, and nine of the eleven adapters import domain modules back, so the seam is two-way and the dependency rule does not hold.

Solution: Either record the actual shape (adapters are a shared infrastructure tier, not a ports layer) or move the four real ports into a shared location and give the DB schema its own module both sides may import.

  • One direction, not two
  • leverage: one schema module
  • Seam count becomes honest
Contradicts ADR-0001 (hexagonal modular monolith). Worth reopening because the ADR's own rule is already broken by 180 call sites — it documents an intent, not the built shape.
